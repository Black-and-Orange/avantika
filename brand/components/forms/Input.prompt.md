`Input` es el campo de texto de los formularios de contacto.

```jsx
<Input label="Nombre completo" />
<Input label="Correo de trabajo" placeholder="nombre@empresa.com" />
<Input label="Teléfono" hint="Con lada" />
```

La etiqueta siempre va arriba y visible; el placeholder no la sustituye. Faltan estados de error y éxito: la paleta no tiene colores de estado. Propuesta BnO.
